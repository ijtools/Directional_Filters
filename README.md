# Directional Filters Plugins

Directional_Filters is a library of plugins for ImageJ that provides facilities for directional filtering. 
It is based (and extends) the MorphoLibJ library, by allowing to apply filters based on an oriented line structuring element with arbitrary orientation.

The Directional Filters library currenlty provides two plugins:

* "**Directional Filtering**" allows for directional filtering by specifying operator, length, thickness, and orientation of the line structuring element
* "**Orientation Stack**" repeats operation for many orientations, and creates a stack concatenating the results.
